# RISC OS Image Organiser

Image Organiser is a native RISC OS image browser, viewer, and lightweight
organiser written in C using OSLib and built with GCCSDK.

Development targets Windows 11 with WSL2 Ubuntu for cross-compilation and
RPCEmu for testing.
